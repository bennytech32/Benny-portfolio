IT TECH EXPERT PORTFOLIO - PROFILE PICTURE INSTRUCTIONS
=======================================================

To use your own picture:
1. Copy your personal photo into this 'public' folder.
2. Name it 'profile.jpg' (or 'profile.png' / 'profile.webp').
3. If you use a different name or format (like 'my-photo.png'), 
   you can simply update the image source in 'index.html' 
   at line: <img src="public/profile.jpg" ...> 
   or use the live "Change Picture" button directly on the website!

Current active picture: public/profile.jpg
Recommended dimensions: Square aspect ratio (e.g., 800x800 px or higher).
